# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

This is an AI literacy training course for faculty at **Salem Community College (SCC)**. Currently the repository contains a single self-contained interactive HTML activity: `faculty-ai-readiness-inventory.html`. There is no build system, package manager, or test framework — the file runs directly in any browser.

## Running the Activity

Open `faculty-ai-readiness-inventory.html` directly in a browser. No server is required.

## Architecture

The file is a single-page multi-step wizard with all HTML, CSS, and JavaScript inline. The five sections (`sec-welcome`, `sec-framework`, `sec-inventory`, `sec-reflection`, `sec-complete`) are all present in the DOM; visibility is controlled by toggling the `.active` CSS class. Only one section is visible at a time.

**State** is stored entirely in memory in a `responses` plain object (keys like `item_0` through `item_11`) — there is no persistence, localStorage, or backend. All state is lost on page reload.

**Navigation** flows through the `sectionOrder` array via `goTo(id)`, which also drives the sticky progress bar. The back buttons call `goTo()` directly; the forward buttons on inventory and reflection call validation functions (`checkInventory()`, `checkReflection()`) first.

**Content data** lives in two JS arrays at the top of the `<script>` block:
- `inventoryItems` — 12 self-assessment statements, each tagged with a domain index (0–3)
- `domains` — 4 pedagogical domains: Conceptual Fluency, Pedagogical Design, Academic Integrity, Disciplinary Judgment

The inventory HTML is **dynamically built** by `buildInventory()` on page load — it is not in the HTML source. Domain dividers are inserted whenever the domain index changes, relying on `inventoryItems` being sorted by domain.

**Scoring** aggregates `responses` into three buckets: `got` / `figuring` / `lost`. Domain-level scores use a plurality rule in `getDomainCounts()`. These drive the summary panels on the Reflection and Completion screens.

**Output** for Canvas LMS submission is generated by `getResponseText()` as a plain-text blob. The Copy button uses `navigator.clipboard.writeText()` with a fallback to `showPrintOutput()` (renders the text in a visible `<pre>`-like div).

## Design System

All colors and radii use CSS custom properties defined in `:root`. Key tokens:

| Token | Value | Usage |
|---|---|---|
| `--scc-green` | `#016450` | Primary brand color |
| `--scc-green-dk` | `#014a3c` | Hover states |
| `--scc-green-lt` | `#e8f4f1` | Light backgrounds, callouts |
| `--radius` | `6px` | All border radii |
| `--transition` | `0.2s ease` | All interactive transitions |

Typography: **Source Serif 4** (headings via `.hero h1`, `.section-header h2`) and **DM Sans** (body and UI), both loaded from Google Fonts.

The three inventory rating pill states use distinct color sets: green (`pill-got`), amber (`pill-figuring`), and red (`pill-lost`).

## Key Conventions

- **Accessibility**: Interactive elements use `aria-pressed` (rating buttons), `role="group"`, `role="alert"` (warning boxes), and `role="progressbar"`. The skip link targets `#main`. Maintain these when adding new interactive elements.
- **Validation warnings** (`warn-box`) are shown inline (via `style.display = 'block'`) and focused programmatically. They are hidden by default in CSS.
- The `answered` class on `.inventory-item` turns the border green — it is added in `selectRating()` and should be kept in sync with any inventory refactor.
- Word count feedback in the reflection section turns green (`.enough`) at 40+ words.

## Institutional Context

- The course targets **faculty**, not students. Tone and framing assume professional educators assessing their own pedagogical readiness.
- The inventory is grounded in the **U.S. Department of Labor's 2026 AI Literacy Framework** (5 competencies referenced in the Framework section).
- Submission target is the **Canvas LMS** ("Learn Module: AI Readiness Reflection" assignment). The copy/export flow must produce clean plain text suitable for pasting into a Canvas text box.
- SCC = Salem Community College (New Jersey).
